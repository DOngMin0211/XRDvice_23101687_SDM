// 물건 수리 및 분류 (콘셉트 모티프 포탈, 안도르) 

= 엔진 오브젝트(프리팹 에셋), 스페어 오브젝트(빨간색)
[ 엔진 오브젝트 2곳 수리 후 분류, 스페어 오브젝트 일반 분류 ]
= 목표 점수 설정
= 시스템 버튼 클릭 및 분류량. 할당량
= 분류량 각각 10점씩
= 할당량 버튼 
= 틀리게 넣을 경우 점수 -1

시작 
1. 방 안에 있는 버튼을 누르면 문이 열림
2. 연구실 내부에 있는 버튼을 누르면 위쪽 2개의 통로에서 각각 엔진 오브젝트, 스페어 오브젝트가 개수 랜덤 생성되어 나옴
3. 랜덤으로 생성된 엔진 오브젝트와 스페어 오브젝트를 각 위치에 맞게 둔다.
   [엔진 오브젝트 . 2개의 부위를 수리하여 표시된 통로에 알맞게 분류] / 만일, 수리를 정상적으로 하지 않고 분류했다면 0.5점
   [스페어 오브젝트 . 일반적으로 표시된 통로에 알맞게 분류]
4. 분류에 알맞게 넣지 않고, 잘못 넣을 시 해당 통로에 -1점
5. 할당량을 채울 때까지 반복
6. 할당량을 모두 채우면 모든 시스템 정지 및 종료 UI 생성
7. 방으로 돌아와 문을 닫는 버튼을 누르면 게임 끝

8. ex. 방에 있는 총으로 감시 터렛에게 조준하거나 사격할 시 게임 패배(사망)


발전기 고치기 게임

1. 문을 열고 입장
2. 발전기 0% ~ 100%가 될 때까지 수리
3. 배터리 교체 / 주어진 버튼을 누르면 배터리가 배부됨.
